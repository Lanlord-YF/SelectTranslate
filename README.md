# 划词翻译 SelectTranslate

一个很小的 Windows 小工具：在任意程序里用鼠标拖选一段文字，松手之后它会自动把这段文字翻译成中文，并在光标旁边弹出一个深色小窗。

不用登录、不用填 API Key、不装浏览器插件。翻译走的是 Bing 翻译网页版那个免费接口，整个程序只用 Python 标准库写的，没有任何第三方依赖。

## 直接用

下载 `SelectTranslate.exe`，双击就能跑，不用装 Python 也不用装别的什么。

启动后它没有窗口、没有托盘图标，就那么悄悄待在后台。用法：

1. 在浏览器、PDF 阅读器、Word 里，用左键拖选一段外文
2. 松开鼠标（位移要超过 5 像素、按住超过 0.08 秒才算「划词」）
3. 稍等一下，译文会在你松手的位置右边弹出来
4. 点屏幕任意地方，或者滚一下滚轮，小窗立刻消失

按 `Ctrl+Alt+Q` 退出。想让它开机自动跑，把 exe 的快捷方式丢进 `Win+R → shell:startup` 打开的那个文件夹就行。

> 注意：程序自带单实例保护。已经有一份在跑的时候再双击，新的那份会自己退掉，不会再弹一个窗口出来。

## 从源码跑

需要 Python 3.10 以上，装了 tkinter 就行（Windows 官方发行版默认带）。

```powershell
pythonw 划词翻译.py
```

用 `pythonw` 而不是 `python`，不然会多挂一个黑窗口。

## 快捷键

| 按键 | 作用 |
|---|---|
| `Ctrl + Alt + P` | 暂停 / 恢复划词 |
| `Ctrl + Alt + Q` | 退出程序 |

暂停之后钩子还在，但不再响应拖选，适合开会或者要精细操作鼠标的时候用。

## 它会跳过哪些文字

不是所有选中都会被翻译，下面这些会直接忽略：

- 空的，或者超过 2000 字的
- 超过 40 行的
- 中文占比超过一半的（本来就是中文，没必要翻）

另外两次取词之间有 350 毫秒的冷却，防止手抖连划。

## 翻译方向

目标永远是中文，不会出现「中文被翻成英文」：

- **纯英文**：整段英译中，请求时显式指定源语言是英文（不让 Bing 自动识别，否则 `TCP` 会被当成德语而原样返回）
- **中英混排**：只把英文片段送去翻译，中文部分原样保留，再按原位置拼回去
- **缩写**（`WAF`、`TCP` 这类）：Bing 翻译常常原样返回，这时改用必应词典的词条释义，弹窗里显示成两行

## 怎么回事（给想改代码的人）

三条线程分工：

```
鼠标事件 → 钩子线程 → events 队列 → 工作线程 → ui_queue → 主线程(Tk 界面)
```

钩子跑在 `WH_MOUSE_LL` 上，回调用 `LButtonDown/LButtonUp` 判断你是不是在拖选。判定成立就把坐标丢进队列，工作线程接手：先备份剪贴板，清空，模拟一次 `Ctrl+C`，轮询读回内容，再把原剪贴板还原，最后发给 Bing 翻译。界面那边只负责画窗口。

## 想改点什么

源码顶部的「配置区」是给使用者自己填的地方，改完保存就生效：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `APP_PATH` | `C:\Tools\SelectTranslate.exe` | 只是弹窗底部「恢复使用」显示的路径，换成你自己程序所在的位置；不换也不影响翻译 |
| `MAX_CHARS` | 2000 | 超过多少字就不翻 |
| `MIN_CHARS` | 1 | 至少几个字才翻 |
| `DRAG_THRESHOLD` | 5 | 鼠标移动多少像素才算划选 |
| `COOLDOWN_MS` | 350 | 两次取词的间隔，嫌太快就调大 |
| `POPUP_TIMEOUT_MS` | 30000 | 弹窗多久自动消失 |
| `POPUP_MAX_WIDTH` | 460 | 弹窗宽度上限 |
| `SKIP_IF_MOSTLY_CJK` | True | 原文中文过半就跳过 |

快捷键也在这附近，`Ctrl+Alt+P` 暂停、`Ctrl+Alt+Q` 退出，冲突的话改 `hook_thread()` 里 `RegisterHotKey` 的键值。

## 可能会遇到的问题

**第一次跑被安全软件拦了。** 程序装了全局鼠标钩子又模拟键盘，这个组合在 360、火绒这类软件眼里跟键盘记录器很像，可能会直接拦掉。表现是划词完全没反应，或者提示「安装鼠标钩子失败」。给 exe 加个白名单就好。

**某些程序里划词没反应。** 取词靠模拟 `Ctrl+C`，所以凡是本身不支持复制的地方都不行：cmd、PowerShell 窗口（要开「快速编辑」才行）、部分游戏、CAD 之类的自绘界面。浏览器、Word、PDF 阅读器这些基本没问题。

**偶尔翻译失败，提示 token 解析失败。** Bing 那边改网页结构了。这接口不是官方的，微软随时能动。遇到这种情况只能等作者改，或者自己去 `_bing_token()` 里把正则更新一下。

**剪贴板里的东西会变吗。** 理论上不会。程序会先存下来，取完词再原样放回去，正常情况你察觉不到。但如果复制的是图片、文件这类非文本内容，可能会丢——因为程序只备份纯文本。

**第一次启动比较慢。** onefile 打包的 exe 每次启动都要先把内容解压到临时目录，大概一两秒。介意这点的话可以自己 `--onedir` 重新打包。

## 已知限制

- 依赖 Bing 的非官方接口，它一变就不能用了。不会变成收费，只会直接坏掉。
- 不能完全离线。想离线得接本地模型（比如 Argos Translate），但要几百兆的模型文件，而且慢。
- 目标语言写死是简体中文。
- 没有缓存，同一段文字反复划会反复请求。
